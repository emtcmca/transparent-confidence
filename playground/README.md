# transparent-confidence playground

Runnable demo of the [`transparent-confidence`](https://github.com/emtcmca/transparent-confidence) npm package (v0.3): four RAG scenarios showing scores, labels, recommended actions, and warning codes.

[Open in StackBlitz](https://stackblitz.com/github/emtcmca/transparent-confidence/tree/master/playground?file=index.js) *(link works once this folder is on GitHub `master`)*

## Run locally

```bash
cd playground
npm install
npm start
```
